// Módulo 1
¿Cómo se conectan todas las piezas?
En las clases anteriores usaste Python solo (con Tkinter). Ahora el "frente" (lo que ve el usuario) está hecho en HTML+CSS+JS, y Python actúa como el intermediario inteligente que recibe peticiones, consulta la base de datos y devuelve la respuesta.
🏷
HTML
Estructura de la página. Botones, tablas, formularios.
🎨
CSS
Estilo visual. Colores, fuentes, tamaños, layouts.
⚡
JavaScript
Interactividad. Envía datos a Flask sin recargar.
🐍
Flask
Servidor Python. Procesa peticiones y consulta la BD.
🗄
SQLite
Base de datos. Guarda los productos permanentemente.
💡
El flujo completo: el usuario hace clic en "Agregar producto" → JS captura el formulario y lo envía a Flask → Flask (Python) recibe los datos, los guarda en SQLite, y responde con JSON → JS actualiza la tabla en pantalla sin recargar la página.
⚠️
Diferencia clave con la clase 4: en Tkinter todo corría localmente en una ventana. Con Flask, tu Python actúa como un servidor web real — los archivos HTML se sirven a través del navegador en http://localhost:5000. No abres el HTML con doble clic.

// Módulo 3
Estructura del proyecto
Flask tiene convenciones de carpetas que debemos respetar. templates/ es donde van los HTML, static/ es donde van CSS y JS.
catalogo_web/ ├── app.py # ← servidor Flask + rutas + lógica Python ├── catalogo.db # ← se crea automáticamente al correr ├── templates/ │ └── index.html # ← la página que ve el usuario └── static/ ├── style.css # ← estilos visuales └── app.js # ← JavaScript del lado del cliente
⚠️
Las carpetas templates/ y static/ deben llamarse exactamente así — Flask las busca por nombre. Si las llamas diferente, no encontrará los archivos y dará error.

// Módulo 4
Flask — el servidor Python (app.py)
Flask es el núcleo de todo. Recibe peticiones del navegador, consulta SQLite y devuelve la respuesta. Cada @app.route() es una "puerta" que el navegador puede tocar.
app.py — Parte 1: setup, BD y ruta principal
from flask import Flask, jsonify, request, render_template import sqlite3 app = Flask(__name__) DB = "catalogo.db" # ── Conexión y creación de tabla ────────────────── def get_db(): conn = sqlite3.connect(DB) conn.row_factory = sqlite3.Row # las filas se comportan como dicts return conn def init_db(): conn = get_db() conn.execute(""" CREATE TABLE IF NOT EXISTS productos ( id INTEGER PRIMARY KEY AUTOINCREMENT, nombre TEXT NOT NULL, precio REAL NOT NULL, stock INTEGER NOT NULL, categoria TEXT NOT NULL ) """) conn.commit() conn.close() # ── Ruta principal — sirve el HTML ─────────────── @app.route("/") def index(): return render_template("index.html") # busca en templates/
app.py — Parte 2: rutas CRUD
# ── GET /productos — leer todos ────────────────── @app.route("/productos", methods=["GET"]) def get_productos(): conn = get_db() filas = conn.execute("SELECT * FROM productos").fetchall() conn.close() return jsonify([dict(f) for f in filas]) # ── POST /productos — crear ─────────────────────── @app.route("/productos", methods=["POST"]) def crear_producto(): d = request.get_json() conn = get_db() conn.execute( "INSERT INTO productos (nombre, precio, stock, categoria) VALUES (?,?,?,?)", (d["nombre"], d["precio"], d["stock"], d["categoria"]) ) conn.commit() conn.close() return jsonify({"ok": True}), 201 # ── PUT /productos/<id> — editar ───────────────── @app.route("/productos/<int:id>", methods=["PUT"]) def editar_producto(id): d = request.get_json() conn = get_db() conn.execute( "UPDATE productos SET nombre=?, precio=?, stock=?, categoria=? WHERE id=?", (d["nombre"], d["precio"], d["stock"], d["categoria"], id) ) conn.commit() conn.close() return jsonify({"ok": True}) # ── DELETE /productos/<id> — eliminar ──────────── @app.route("/productos/<int:id>", methods=["DELETE"]) def eliminar_producto(id): conn = get_db() conn.execute("DELETE FROM productos WHERE id=?", (id,)) conn.commit() conn.close() return jsonify({"ok": True}) # ── Arranque ────────────────────────────────────── if __name__ == "__main__": init_db() app.run(debug=True)
💡
row_factory = sqlite3.Row convierte cada fila de la base de datos en un objeto que funciona como diccionario — así podemos hacer dict(fila) y convertirlo a JSON fácilmente para enviarlo al navegador.

// Módulo 6
JavaScript — Fetch API (sin recargar)
Aquí está la magia: fetch() permite que JS hable directamente con Flask en segundo plano. El usuario hace clic → JS envía datos → Flask responde con JSON → JS actualiza la tabla. Todo sin recargar la página.
static/app.js — Leer y mostrar productos
// Se ejecuta al cargar la página por primera vez cargarProductos(); async function cargarProductos() { // 1. Pide todos los productos a Flask (GET /productos) const res = await fetch("/productos"); const productos = await res.json(); // ← Flask devuelve JSON, JS lo convierte en array // 2. Genera una fila HTML por cada producto const tbody = document.getElementById("tbody"); tbody.innerHTML = productos.map(p => ` <tr> <td>${p.id}</td> <td>${p.nombre}</td> <td>$${p.precio.toFixed(2)}</td> <td>${p.stock}</td> <td>${p.categoria}</td> <td> <button class="btn-editar" onclick="cargarEdicion(${p.id},'${p.nombre}',${p.precio},${p.stock},'${p.categoria}')">editar</button> <button class="btn-eliminar" onclick="eliminar(${p.id})">eliminar</button> </td> </tr> `).join(""); }
static/app.js — Guardar (crear o editar)
async function guardar() { const id = document.getElementById("inp-id").value; const nombre = document.getElementById("inp-nombre").value.trim(); const precio = parseFloat(document.getElementById("inp-precio").value); const stock = parseInt(document.getElementById("inp-stock").value); const categoria = document.getElementById("inp-categoria").value.trim(); if (!nombre || isNaN(precio) || isNaN(stock) || !categoria) { alert("Completa todos los campos."); return; } const datos = { nombre, precio, stock, categoria }; if (id) { // Tiene ID → EDITAR (PUT) await fetch(`/productos/${id}`, { method: "PUT", headers: { "Content-Type": "application/json" }, body: JSON.stringify(datos) }); } else { // Sin ID → CREAR (POST) await fetch("/productos", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(datos) }); } limpiar(); cargarProductos(); // recarga la tabla automáticamente }
static/app.js — Editar y Eliminar
function cargarEdicion(id, nombre, precio, stock, categoria) { // Llena los campos del formulario con los datos del producto seleccionado document.getElementById("inp-id").value = id; document.getElementById("inp-nombre").value = nombre; document.getElementById("inp-precio").value = precio; document.getElementById("inp-stock").value = stock; document.getElementById("inp-categoria").value = categoria; } async function eliminar(id) { if (!confirm("¿Eliminar este producto?")) return; await fetch(`/productos/${id}`, { method: "DELETE" }); cargarProductos(); } function limpiar() { ["inp-id", "inp-nombre", "inp-precio", "inp-stock", "inp-categoria"] .forEach(id => document.getElementById(id).value = ""); }
💡
async/await hace que JS espere la respuesta de Flask antes de continuar. Sin esto, el código seguiría ejecutándose antes de recibir los datos y la tabla quedaría vacía. Es la forma moderna de manejar operaciones que tardan tiempo (como llamadas a red o base de datos).
