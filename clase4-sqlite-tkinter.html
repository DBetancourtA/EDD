// Módulo 1
¿Qué es una base de datos?
Hasta ahora hemos guardado datos en listas y diccionarios que desaparecen cuando el programa termina. Una base de datos guarda la información en un archivo en disco — los datos persisten para siempre.
🐍 Lista en Python (temporal)
estudiantes = [ {"nombre": "Ana", "nota": 9.5}, {"nombre": "Luis", "nota": 8.0} ] # ❌ Al cerrar el programa, se pierde todo
🗄️ SQLite (permanente)
# Los datos viven en estudiantes.db INSERT INTO estudiantes VALUES ('Ana', 9.5); # ✅ Siguen ahí aunque cierres Python
📁
Archivo .db
SQLite guarda todo en un solo archivo (ej: estudiantes.db). Puedes copiarlo, enviarlo por correo — los datos van con él.
📋
Tabla
Como una hoja de cálculo: filas (registros) y columnas (campos). Una base de datos puede tener muchas tablas.
🔑
Primary Key
Un identificador único para cada fila — como el número de cédula. SQLite lo genera automáticamente con AUTOINCREMENT.
💬
SQL
El lenguaje para hablarle a la base de datos. 5 comandos son todo lo que necesitas para el CRUD completo.

// Módulo 2
Conectarse a SQLite desde Python
Para usar una base de datos desde Python necesitas tres objetos clave: la conexión, el cursor y el commit. Piénsalos como abrir un cuaderno, escribir con lápiz, y confirmar los cambios.
// Los tres objetos que siempre usarás
🔌
conexion
Abre (o crea) el archivo .db. Si no existe, SQLite lo crea en ese momento.
✏️
cursor
El "lápiz" que ejecuta los comandos SQL. Todo pasa a través de él con .execute().
💾
commit
Guarda los cambios en el archivo. Sin .commit() las inserciones y ediciones no se guardan.
conexion_basica.py
import sqlite3 # 1. Conectar (crea el archivo si no existe) conexion = sqlite3.connect("estudiantes.db") # 2. Crear el cursor (el "lápiz" que ejecuta SQL) cursor = conexion.cursor() # 3. Crear la tabla si no existe todavía cursor.execute(""" CREATE TABLE IF NOT EXISTS estudiantes ( id INTEGER PRIMARY KEY AUTOINCREMENT, nombre TEXT NOT NULL, carrera TEXT NOT NULL, nota REAL NOT NULL ) """) # 4. Guardar los cambios conexion.commit() print("Base de datos lista ✓")
💡
CREATE TABLE IF NOT EXISTS — este comando crea la tabla solo si no existe. Si la ejecutas dos veces no da error. Es el patrón estándar para inicializar una base de datos.
⚠️
¿Dónde se crea el archivo .db? En la misma carpeta donde esté tu archivo .py. En VS Code puedes verlo aparecer en el explorador de archivos de la izquierda después de ejecutar el programa por primera vez.
// Módulo 3
SQL — Los 5 comandos del CRUD
CRUD significa Create, Read, Update, Delete — las cuatro operaciones de cualquier sistema de datos. En SQL, cada una tiene su propio comando.
CREATE → INSERT READ → SELECT UPDATE → UPDATE DELETE → DELETE
// C — INSERT: agregar un registro
INSERT — agregar estudiante
# Los ? son placeholders — NUNCA pegues variables directamente # (previene ataques de inyección SQL) cursor.execute( "INSERT INTO estudiantes (nombre, carrera, nota) VALUES (?, ?, ?)", ("Ana García", "Administración", 9.5) ) conexion.commit() # ← no olvides esto
💡
Los signos ? son marcadores de posición — SQLite los reemplaza con los valores de la tupla en orden. Siempre usa ? en vez de formatear el string directamente con f"...{variable}...".
// R — SELECT: leer registros
SELECT — leer estudiantes
# Obtener TODOS los estudiantes cursor.execute("SELECT * FROM estudiantes") todos = cursor.fetchall() # retorna una lista de tuplas for fila in todos: print(fila) # Resultado: (1, 'Ana García', 'Administración', 9.5) # Buscar UN estudiante por id cursor.execute("SELECT * FROM estudiantes WHERE id = ?", (1,)) uno = cursor.fetchone() # retorna una sola fila (o None)
// U — UPDATE: modificar un registro
UPDATE — editar estudiante
# El WHERE es crucial — sin él actualizas TODA la tabla cursor.execute( "UPDATE estudiantes SET nota = ?, carrera = ? WHERE id = ?", (9.8, "Contabilidad", 1) ) conexion.commit()
⚠️
Siempre usa WHERE en UPDATE y DELETE. Si olvidas el WHERE id = ?, el comando modifica o elimina todos los registros de la tabla — no hay Ctrl+Z en SQL.
// D — DELETE: eliminar un registro
DELETE — eliminar estudiante
cursor.execute( "DELETE FROM estudiantes WHERE id = ?", (1,) # ← nota la coma: es una tupla de un elemento ) conexion.commit()
💡
(1,) con coma — en Python, (1) es simplemente el número 1 entre paréntesis, no una tupla. Para hacer una tupla de un elemento necesitas la coma: (1,). SQLite espera una tupla, no un número suelto.

Tk() — Ventana
La ventana principal. Toda la app vive dentro de ella. Se abre con .mainloop().
🏷️
Label — Etiqueta
Texto fijo en la ventana. Sirve para los nombres de campos como "Nombre:" o "Carrera:".
📝
Entry — Campo de texto
Caja de entrada editable. El usuario escribe aquí. Se lee con .get().
🔘
Button — Botón
Ejecuta una función al hacer clic. Se conecta con el parámetro command=.
📋
Treeview — Tabla
Muestra datos en filas y columnas, como una tabla. Viene en el módulo ttk.
// Estructura básica de una ventana Tkinter
ventana_basica.py
import tkinter as tk from tkinter import ttk, messagebox # 1. Crear la ventana principal ventana = tk.Tk() ventana.title("Sistema de Estudiantes — ITB") ventana.geometry("640x480") # ancho x alto en píxeles # 2. Crear una etiqueta y un campo de texto tk.Label(ventana, text="Nombre:").grid(row=0, column=0, padx=8, pady=6) entry_nombre = tk.Entry(ventana, width=30) entry_nombre.grid(row=0, column=1, padx=8, pady=6) # 3. Crear un botón que ejecuta una función def saludar(): nombre = entry_nombre.get() messagebox.showinfo("Hola", f"Hola, {nombre}!") tk.Button(ventana, text="Saludar", command=saludar).grid( row=1, column=1, pady=8 ) # 4. Iniciar el loop de la ventana (siempre al final) ventana.mainloop()
💡
.grid(row=, column=) es el sistema de posicionamiento. Piénsalo como una tabla: row=0 es la primera fila, column=0 es la primera columna. padx y pady añaden espacio alrededor.
// Módulo 5
El CRUD completo — SQLite + Tkinter unidos
Ahora unimos todo. El programa completo tiene: conexión a la base de datos, una ventana con campos de entrada, cuatro botones y una tabla que muestra todos los registros en tiempo real.
1
Importa las librerías y conecta la base de datos al inicio del archivo
2
Define las 4 funciones del CRUD: agregar(), leer(), editar(), eliminar()
3
Construye la ventana: Labels + Entries para los campos, Buttons conectados a las funciones, Treeview para mostrar los datos
4
Llama a leer() al inicio para cargar los datos existentes
5
Inicia el loop con ventana.mainloop()
crud_estudiantes.py — PARTE 1: setup y funciones
import sqlite3 import tkinter as tk from tkinter import ttk, messagebox # ── BASE DE DATOS ────────────────────────────── conexion = sqlite3.connect("estudiantes.db") cursor = conexion.cursor() cursor.execute(""" CREATE TABLE IF NOT EXISTS estudiantes ( id INTEGER PRIMARY KEY AUTOINCREMENT, nombre TEXT NOT NULL, carrera TEXT NOT NULL, nota REAL NOT NULL ) """) conexion.commit() # ── FUNCIONES CRUD ───────────────────────────── def leer(): """Carga todos los registros en la tabla visual""" for fila in tabla.get_children(): tabla.delete(fila) # limpia la tabla visual cursor.execute("SELECT * FROM estudiantes") for registro in cursor.fetchall(): tabla.insert("", tk.END, values=registro) def agregar(): """Lee los campos y guarda un nuevo estudiante""" nombre = entry_nombre.get().strip() carrera = entry_carrera.get().strip() nota = entry_nota.get().strip() if not nombre or not carrera or not nota: messagebox.showwarning("Aviso", "Completa todos los campos.") return try: cursor.execute( "INSERT INTO estudiantes (nombre, carrera, nota) VALUES (?, ?, ?)", (nombre, carrera, float(nota)) ) conexion.commit() leer() limpiar_campos() except ValueError: messagebox.showerror("Error", "La nota debe ser un número.") def editar(): """Actualiza el registro seleccionado en la tabla""" seleccion = tabla.focus() if not seleccion: messagebox.showwarning("Aviso", "Selecciona un estudiante de la tabla.") return id_sel = tabla.item(seleccion)["values"][0] try: cursor.execute( "UPDATE estudiantes SET nombre=?, carrera=?, nota=? WHERE id=?", (entry_nombre.get(), entry_carrera.get(), float(entry_nota.get()), id_sel) ) conexion.commit() leer() limpiar_campos() except ValueError: messagebox.showerror("Error", "La nota debe ser un número.") def eliminar(): """Elimina el registro seleccionado con confirmación""" seleccion = tabla.focus() if not seleccion: messagebox.showwarning("Aviso", "Selecciona un estudiante de la tabla.") return id_sel = tabla.item(seleccion)["values"][0] conf = messagebox.askyesno("Confirmar", "¿Eliminar este estudiante?") if conf: cursor.execute("DELETE FROM estudiantes WHERE id = ?", (id_sel,)) conexion.commit() leer() limpiar_campos() def seleccionar_fila(event): """Al hacer clic en la tabla, carga los datos en los campos""" seleccion = tabla.focus() if seleccion: valores = tabla.item(seleccion)["values"] limpiar_campos() entry_nombre.insert(0, valores[1]) entry_carrera.insert(0, valores[2]) entry_nota.insert(0, valores[3]) def limpiar_campos(): """Vacía los campos de texto""" entry_nombre.delete(0, tk.END) entry_carrera.delete(0, tk.END) entry_nota.delete(0, tk.END)
crud_estudiantes.py — PARTE 2: ventana e interfaz
# ── VENTANA ──────────────────────────────────── ventana = tk.Tk() ventana.title("Sistema de Estudiantes — ITB") ventana.geometry("680x500") ventana.resizable(True, True) # ── CAMPOS DE ENTRADA ────────────────────────── tk.Label(ventana, text="Nombre:", font=("Arial", 11)).grid(row=0, column=0, padx=10, pady=8, sticky="e") entry_nombre = tk.Entry(ventana, width=35, font=("Arial", 11)) entry_nombre.grid(row=0, column=1, padx=10, pady=8, columnspan=2) tk.Label(ventana, text="Carrera:", font=("Arial", 11)).grid(row=1, column=0, padx=10, pady=8, sticky="e") entry_carrera = tk.Entry(ventana, width=35, font=("Arial", 11)) entry_carrera.grid(row=1, column=1, padx=10, pady=8, columnspan=2) tk.Label(ventana, text="Nota:", font=("Arial", 11)).grid(row=2, column=0, padx=10, pady=8, sticky="e") entry_nota = tk.Entry(ventana, width=15, font=("Arial", 11)) entry_nota.grid(row=2, column=1, padx=10, pady=8, sticky="w") # ── BOTONES ──────────────────────────────────── frame_btns = tk.Frame(ventana) frame_btns.grid(row=3, column=0, columnspan=3, pady=10) tk.Button(frame_btns, text="➕ Agregar", bg="#2d6a4f", fg="white", command=agregar, width=12).grid(row=0, column=0, padx=5) tk.Button(frame_btns, text="✏️ Editar", bg="#1d3557", fg="white", command=editar, width=12).grid(row=0, column=1, padx=5) tk.Button(frame_btns, text="🗑️ Eliminar", bg="#9e2a2b", fg="white", command=eliminar, width=12).grid(row=0, column=2, padx=5) tk.Button(frame_btns, text="🔄 Actualizar", bg="#555", fg="white", command=leer, width=12).grid(row=0, column=3, padx=5) # ── TABLA (TREEVIEW) ─────────────────────────── cols = ("ID", "Nombre", "Carrera", "Nota") tabla = ttk.Treeview(ventana, columns=cols, show="headings", height=12) for col in cols: tabla.heading(col, text=col) tabla.column(col, width=140 if col != "ID" else 50) tabla.grid(row=4, column=0, columnspan=3, padx=10, pady=10, sticky="nsew") tabla.bind("<<TreeviewSelect>>", seleccionar_fila) # Scrollbar para la tabla scroll = ttk.Scrollbar(ventana, orient="vertical", command=tabla.yview) scroll.grid(row=4, column=3, sticky="ns", pady=10) tabla.configure(yscrollcommand=scroll.set) # Expandir tabla al redimensionar ventana ventana.grid_rowconfigure(4, weight=1) ventana.grid_columnconfigure(1, weight=1) # ── INICIO ───────────────────────────────────── leer() # cargar datos al abrir ventana.mainloop() # iniciar la ventana
