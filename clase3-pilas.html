Estructuras de Datos Abstractas Lineales
Una estructura de datos abstracta (EDA) define qué operaciones puede hacer una colección de datos, sin importar cómo están implementadas internamente. Las estructuras lineales organizan sus elementos en una sola dimensión: cada elemento tiene un predecesor y un sucesor (excepto el primero y el último). Las tres estructuras lineales fundamentales son:

// ¿Qué es una Pila?
Last In · First Out
Principio LIFO
Una pila es una colección de elementos donde las operaciones de inserción y extracción ocurren siempre por el mismo extremo, llamado tope (top). El último elemento en entrar es el primero en salir.

En Python, una pila se implementa directamente con una lista vacía usando .append() para apilar y .pop() para desapilar. No necesitas importar nada.
