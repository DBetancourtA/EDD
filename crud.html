01 Conectar SQLite

¿Qué es SQLite? Es una base de datos pequeña, rápida y confiable que se almacena en un archivo. No necesita un servidor separado, ¡perfecto para aprender!

¿Qué hace este código? Conecta Python a una base de datos SQLite. Si el archivo no existe, lo crea automáticamente.

import sqlite3 conexion = sqlite3.connect("estudiantes.db") cursor = conexion.cursor()

02 Create (Crear)

¿Qué es CREATE? Significa agregar nuevos datos a la base de datos. En este caso, agregamos un nuevo estudiante con su nombre y edad.

Cómo funciona: INSERT INTO inserta (mete) datos nuevos en la tabla. Los "?" son marcadores de posición seguros para los valores.

cursor.execute("INSERT INTO estudiantes(nombre,edad) VALUES(?,?)", ("Juan", 22)) conexion.commit()

03 Read (Leer)

¿Qué es READ? Significa leer o consultar datos que ya existen en la base de datos. Es solo lectura, no modifica nada.

Cómo funciona: SELECT * FROM obtiene todos los registros. fetchall() devuelve todos los resultados como una lista de tuplas.

cursor.execute("SELECT * FROM estudiantes") estudiantes = cursor.fetchall() print(estudiantes)

04 Update (Actualizar)

¿Qué es UPDATE? Significa modificar datos que ya existen. Por ejemplo, cambiar la edad de un estudiante.

Cómo funciona: UPDATE cambia valores. WHERE especifica cuál registro modificar. ¡Siempre usa WHERE o cambiarás TODO!

cursor.execute("UPDATE estudiantes SET edad=? WHERE nombre=?", (30, "Juan")) conexion.commit()

05 Delete (Eliminar)

¿Qué es DELETE? Significa borrar datos de la base de datos. ¡Atención! Es destructivo, los datos se pierden.

Cómo funciona: DELETE FROM borra registros. WHERE especifica cuál eliminar. ¡SIEMPRE usa WHERE o perderás todo!

cursor.execute("DELETE FROM estudiantes WHERE nombre=?", ("Juan",)) conexion.commit()

06 Proyecto Completo

🚀 Ahora es tu turno: Deberás crear un programa diferente usando estas operaciones CRUD. Algunas ideas:

  • 📚 Sistema de biblioteca (crear, leer, actualizar y eliminar libros)
  • 🛒 Control de inventario (productos en almacén)
  • 🎮 Lista de videojuegos (con puntuaciones)
  • 🎵 Gestor de canciones favoritas (artista, duración, género)
  • 📝 TODO List (tareas pendientes)
  • 💰 Gestor de gastos (categoría, monto, fecha)

Requisitos del proyecto:

  • Crear una tabla diferente a "estudiantes"
  • Implementar las 4 operaciones CRUD (Create, Read, Update, Delete)
  • Agregar al menos 3 campos diferentes en tu tabla
  • Probar cada operación correctamente
