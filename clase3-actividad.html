Opción 2 — Retroceder ←
▼
Para retroceder necesitas al menos 2 páginas en atras (la actual + una anterior). El tope de atras se mueve a adelante y el nuevo tope de atras pasa a ser la página actual.
a
Verifica: if len(atras) > 1: — necesitas más de una página para retroceder
b
Extrae el tope: pagina = atras.pop()
c
Muévela a adelante: adelante.append(pagina)
d
Muestra la nueva página actual: atras[-1]
opción 2 — retroceder
elif opcion == "2": if len(atras) > 1: pagina = atras.pop() # extraer página actual adelante.append(pagina) # guardar en adelante print(f"← Retrocediendo desde: {pagina}") print(f" Página actual: {atras[-1]}") else: print("No hay páginas anteriores.")
