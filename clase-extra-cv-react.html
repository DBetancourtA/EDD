JavaScript ES6 React 18 (CDN) Sin instalación ● Proyecto final: tu CV
Antes de empezar: No necesitas instalar nada nuevo. Usaremos VS Code (el mismo que ya conoces) y el navegador. React se carga directamente desde internet con una etiqueta <script>, igual que cuando importas una librería en Python — pero aquí no usamos pip install, el navegador la descarga sola.
// Módulo 1
Fundamentos de JavaScript — el puente desde Python
JavaScript y Python comparten muchas ideas: variables, funciones, condicionales, bucles, listas y diccionarios. Lo que cambia es la sintaxis. Vamos a traducir lo que ya sabes.
// 1.1 — Variables
🐍 Python
nombre = "Diego" edad = 28 activo = True
⚡ JavaScript
const nombre = "Diego"; let edad = 28; const activo = true;
💡
Diferencia clave: en JS toda línea termina con punto y coma ; (opcional pero recomendado). Usa const cuando el valor no cambiará nunca, y let cuando sí puede cambiar. Ya no existe var en código moderno.
// 1.2 — Funciones
🐍 Python
def saludar(nombre): return f"Hola {nombre}" print(saludar("Ana"))
⚡ JavaScript
const saludar = (nombre) => { return `Hola ${nombre}`; }; console.log(saludar("Ana"));
💡
Esto es una "arrow function" — la forma moderna de escribir funciones en JS, equivalente a def. El f-string de Python f"texto {var}" se llama template literal en JS: `texto ${var}` — usa comillas invertidas (backticks), no comillas normales.
// 1.3 — Listas (arrays) y recorridos
🐍 Python
habilidades = [ "Python", "SQL", "Excel" ] for h in habilidades: print(h)
⚡ JavaScript
const habilidades = [ "Python", "SQL", "Excel" ]; habilidades.forEach(h => { console.log(h); });
// 1.4 — Diccionarios → Objetos
🐍 Python (dict)
persona = { "nombre": "Diego", "cargo": "Docente" } print(persona["nombre"])
⚡ JavaScript (object)
const persona = { nombre: "Diego", cargo: "Docente" }; console.log(persona.nombre);
💡
Un objeto en JS es prácticamente igual a un dict en Python. La diferencia: en JS normalmente accedes con punto persona.nombre en vez de corchetes con comillas.
⚠️
Nota importante: JavaScript distingue mayúsculas y minúsculas estrictamente, y es muy estricto con llaves { } y paréntesis ( ) — cada apertura necesita su cierre. A diferencia de Python, la indentación no afecta la ejecución (pero igual debes indentar bien para que el código sea legible).
// Módulo 2
¿Qué es React?
React es una librería de JavaScript para construir interfaces. En vez de escribir HTML estático, construyes componentes: piezas reutilizables de interfaz, como funciones que devuelven HTML.
🧩
Componente
Una función que devuelve HTML (en realidad JSX). Como una función de Python que arma un string, pero para interfaces visuales.
📐
JSX
HTML escrito directamente dentro de JavaScript. El navegador lo traduce a elementos visuales reales.
📦
Props
Datos que le pasas a un componente, como argumentos a una función. Permiten reutilizar el mismo componente con datos distintos.
🔄
useState
Permite que un componente "recuerde" valores y la página se actualice sola cuando cambian — como una variable con superpoderes.
// 2.1 — Tu primer componente
1
Un componente es una función que empieza con mayúscula y devuelve JSX (HTML dentro de JS):
Componente básico
// Esto es un componente — observa la mayúscula inicial function Saludo() { return ( <h1>Hola, soy tu primer componente</h1> ); }
💡
Fíjate: dentro de return ( ... ) escribimos HTML directo, sin comillas. Eso es JSX. React lo convierte en una página real.
// 2.2 — Props: pasar datos a un componente
2
Las props son como parámetros de una función — permiten que el mismo componente muestre datos diferentes:
Componente con props
// "props" llega como un objeto con los datos que le pases function Saludo(props) { return <h1>Hola, {props.nombre}</h1>; } // Lo usas así, pasando el dato como atributo HTML: <Saludo nombre="Diego" /> <Saludo nombre="Ana" />
💡
Las llaves { } dentro de JSX significan "aquí va una variable o expresión de JavaScript". Es como el {variable} dentro de un f-string en Python.
// 2.3 — useState: datos que cambian
3
useState guarda un valor y, cuando lo actualizas, la pantalla se redibuja sola — sin recargar la página:
Ejemplo: contador
const { useState } = React; function Contador() { // clicks = valor actual, setClicks = función para cambiarlo const [clicks, setClicks] = useState(0); return ( <button onClick={() => setClicks(clicks + 1)}> Clics: {clicks} </button> ); }
💡
Para nuestro CV no usaremos mucho useState — un CV es información fija. Pero lo verás si luego quieres agregar un botón de "modo oscuro" o un formulario editable.

// Módulo 5
Botón de descarga a PDF
Usaremos window.print() — la función nativa del navegador — combinada con CSS especial para imprimir. Es 100% gratis y no necesita librerías externas.
1
Agrega un botón que llame a window.print() cuando se hace clic
2
Agrega una regla @media print para ocultar el botón cuando se imprime (no debe aparecer en el PDF)
3
El usuario hace clic, eligen "Guardar como PDF" en el diálogo de impresión del navegador
Botón de descarga (dentro de App)
function App() { return ( <> {/* Este botón NO aparece en el PDF, solo en pantalla */} <button className="btn-descargar" onClick={() => window.print()}> 📄 Descargar como PDF </button> <div className="cv-container"> <Encabezado datos={datosCV} /> <p className="cv-resumen">{datosCV.resumen}</p> <Experiencia lista={datosCV.experiencia} /> <Habilidades lista={datosCV.habilidades} /> </div> </> ); }
💡
<> ... </> se llama Fragment — permite devolver dos elementos hermanos (botón + contenedor) sin necesitar un <div> extra envolviéndolos.
CSS del botón + reglas de impresión
.btn-descargar { display: block; margin: 0 auto 16px; background: #6C5CE7; color: white; border: none; padding: 10px 22px; border-radius: 8px; font-size: 14px; font-weight: 600; cursor: pointer; } /* Esta sección SOLO se aplica cuando se imprime o exporta a PDF */ @media print { .btn-descargar { display: none; } /* oculta el botón en el PDF */ body { background: white; padding: 0; } .cv-container { box-shadow: none; border-radius: 0; } }
⚠️
Al hacer clic en "Descargar como PDF": se abre el diálogo de impresión del navegador. El estudiante debe elegir "Guardar como PDF" en el destino/impresora, no "Imprimir" en papel.
